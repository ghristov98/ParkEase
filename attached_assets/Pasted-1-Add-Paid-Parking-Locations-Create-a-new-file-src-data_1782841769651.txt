Marker design:

Red circle SVG marker with a white ⚠ icon centered inside
Slightly larger than the paid parking markers
Subtle pulsing red glow animation (CSS only)
White ring border around the circle
Rendered with the highest zIndex so it always appears above other markers

Behaviour:

Always visible to all users — cannot be hidden by any filter toggle
Cannot be moved, edited, or deleted by anyone, including super admin
In the filter panel, show a non-toggleable row with a red dot + label + "Винаги видим / Always visible" badge instead of a switch

Do not break any existing functionality — map, zones, markers, auth, roles, sessions, filters, navigation
Both languages (Bulgarian and English) must be supported for all new text via the existing i18n system — no hardcoded strings
Fully responsive — desktop and mobile
Ask for these files before touching them: map component, filter panel component, Profile/Settings page component, i18n translation files
