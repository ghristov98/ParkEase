5. Rules

Use OverlayView from @react-google-maps/api for both markers — this gives full control over rendering and prevents clipping
overflow: visible must be set on every SVG element
display: block must be set on every SVG element to remove inline spacing
The padding on the wrapper div gives the glow and shadow room to render without being clipped by the container
Do not use google.maps.Marker with an icon for these — OverlayView is the correct approach for custom SVG markers that need full rendering control
